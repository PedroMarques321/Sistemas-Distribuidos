
# Sistemas distribuidos

## Projeto 1:
O objetivo deste projeto é desenvolver um serviço de armazenamento baseado em pares chave-valor. As estruturas utilizadas para armazenar a informação são uma lista encadeada simples e uma hash-table.

## Projeto 2:
O objetivo deste projeto é concretizar um serviço de armazenamento baseado em pares chave-valor através dum sistema cliente-servidor simples, sendo o servidor responsável por manter uma hash table(estrutura desenvolvida no Projeto1) e sendo o cliente responsável por comunicar com o servidor para realizar operações nesta tabela.

## Projeto 3:
O objetivo deste projeto é desenvolver uma aplicação do tipo cliente-servidor capaz de suportar múltiplos clientes de forma síncrona através de múltiplas threads.

## Instruções:
Instruções para correr os vários projetos encontram-se nos README em cada pasta.
